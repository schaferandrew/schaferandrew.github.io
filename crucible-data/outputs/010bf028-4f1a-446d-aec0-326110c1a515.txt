1. \(N=2^7\cdot 3^4\cdot 7^2\cdot 13\). The solution counts modulo \(128,81,49,13\) are \(8,6,6,12\), so by CRT the count is \(8\cdot6\cdot6\cdot12=3456\).

2. Using inclusion-exclusion over forced adjacencies gives  
\[
\sum_{s=0}^7 (11-s)![t^s]\left(\frac1{24}-\frac t2+\frac{3t^2}2-t^3\right)\left(\frac16-t+t^2\right)\left(\frac12-t\right)^2=6516.
\]

3. Let \(E_i\) be the expected further rolls after a roll of \(i\). Solving the six first-step equations gives  
\[
(E_1,\dots,E_6)=\frac1{61}(115,140,162,167,162,167).
\]
Thus the expected total is
\[
1+\frac{913}{366}=\frac{1279}{366},
\]
so \(m+n=1645\).

4. Use a binary DP with state = last four bits, forbidding adjacent 1s and 1s four apart. Iterating to length 20 gives total \(4867\).

5. For prime exponent \(e\), the number of ordered exponent triples with min \(0\) and max \(e\) is \((e+1)^3-2e^3+(e-1)^3\). Thus ordered triples: \(30\cdot12\cdot6\cdot6=12960\). Subtract repeated-value cases: \(3\cdot2^4=48\), then divide by \(6\), giving \(2152\).

6. Total diagonal-legal paths: \(\binom{20}{8}-\binom{20}{7}=48450\). Paths through \((5,3)\): prefix count \(28\), suffix count \(\binom{12}{5}-\binom{12}{2}=726\). So the answer is \(48450-28\cdot726=28122\).
