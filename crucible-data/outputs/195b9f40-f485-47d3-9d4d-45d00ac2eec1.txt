# Compound‑Interest Calculator

A command‑line tool that calculates compound interest using only the Python standard library.

## Usage

```bash
$ python -m interest \
    --principal 1000 \
    --rate 5 \               # annual rate in %
    --years 2 \               # or --months 24
    --compound monthly \
    --contribution 50 \
    --contribution-frequency monthly \
    [--json                  # print JSON instead of summary
```

## Flags

- `--principal AMOUNT` – Starting balance.
- `--rate PERCENT` – Annual interest rate (e.g., 5 for 5%).
- `--years N` or `--months N` – Duration in whole years or months.
- `--compound {annually|quarterly|monthly|daily}` – Compounding periods per year.
- `--contribution AMOUNT` – Optional contribution (must match frequency).
- `--contribution-frequency {monthly|annually}` – When given, the contribution is added at that interval.
- `--json` – Print JSON instead of a human‑readable summary.

## Example: Monthly contribution, 2 years

```bash
$ python -m interest \
    --principal 1000 \
    --rate 5 \
    --years 2 \
    --compound monthly \
    --contribution 50 \
    --contribution-frequency monthly
```

The tool will add \$50 at the end of each month and apply monthly compounding.

## Running Tests

```bash
$ python -m pytest tests/
```
All tests must pass.
