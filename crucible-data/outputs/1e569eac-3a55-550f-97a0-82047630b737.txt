I have updated the application to make the navbar responsive. 

### Changes Made:
1.  **`index.html`**: Added a `<button class="menu-toggle">` containing three spans to create a "hamburger" icon for mobile users.
2.  **`styles.css`**: 
    *   Added styles for the `.menu-toggle` button to hide it on desktop and show it on mobile.
    *   Implemented a media query (`@media screen and (max-width: 768px)`) to transform the `.nav-links` into a vertical, full-width mobile menu that is hidden by default and revealed when the `.active` class is added.
3.  **`script.js`**: Implemented the logic to toggle the `.active` class on the `.nav-links` element when the menu button is clicked.
4.  **Testing**:
    *   Created a `package.json` file with `playwright` as a dependency.
    *   Added comprehensive Playwright tests in `tests/navbar.spec.js` that verify:
        *   The navigation links are visible on desktop.
        *   The menu toggle appears and correctly shows/hides the links on mobile viewports.
