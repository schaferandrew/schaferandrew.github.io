## **Lesson 1: The Server-First Paradigm**

In standard React (CRA or Vite), your application is a "Client-Side Rendered" (CSR) bundle. The browser downloads a minimal HTML file, a massive JS bundle, and then executes that JS to build the DOM.

In Next.js (App Router), the default is **Server Components (RSC)**.

### **The Concept**
Instead of sending all the logic to the browser, Next.js executes your components on the server. The server sends only the resulting HTML (and a small instruction set for hydration) to the client.

**Key Differences:**
1.  **Server Components (Default):**
    *   **Can:** Fetch data directly (using `async/await`), access databases/file systems, and keep heavy dependencies on the server.
    *   **Cannot:** Use `useState`, `useEffect`, `useContext`, or browser APIs (`window`, `localStorage`).
    *   **Result:** Zero bundle size impact for the logic used in the component.
2.  **Client Components (`'use client'` directive):**
    *   **Can:** Use all React hooks and browser APIs.
    *   **Result:** They are sent to the client for hydration.

**The Golden Rule:** Keep your Client Components at the "leaves" of your component tree. Keep your data fetching and heavy logic in Server Components at the "roots."

### **Example**

**The Server Component (The Data Fetcher):**
```tsx
// app/users/page.tsx (Server Component by default)
import { UserList } from './UserList'; // A Client Component

export default async function UsersPage() {
  // 1. We can fetch data directly in the component!
  const response = await fetch('https://api.example.com/users');
  const users = await response.json();

  return (
    <main>
      <h1>User Directory</h1>
      {/* 2. Pass data down to a Client Component for interactivity */}
      <UserList initialUsers={users} />
    </main>
  );
}
```

**The Client Component (The Interactive Part):**
```tsx
// app/users/UserList.tsx
'use client'; // This tells Next.js to bundle this for the browser

import { useState } from 'react';

export function UserList({ initialUsers }: { initialUsers: any[] }) {
  const [search, setSearch] = useState('');

  return (
    <div>
      <input 
        type="text" 
        onChange={(e) => setSearch(e.target.value)} 
        placeholder="Filter users..." 
      />
      <ul>
        {initialUsers
          .filter(u => u.name.includes(search))
          .map(u => <li key={u.id}>{u.name}</li>)}
      </ul>
    </div>
  );
}
```
