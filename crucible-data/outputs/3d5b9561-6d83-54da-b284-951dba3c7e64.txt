### 1. Divisibility Count
We are looking for the count of integers $N \in [1, 10000]$ such that ($N$ is divisible by 3 OR $N$ is divisible by 7) AND ($N$ is NOT divisible by 21).

Let $A$ be the set of multiples of 3, and $B$ be the set of multiples of 7. We want $|(A \cup B) \setminus (A \cap B)|$.
Since $A \cap B$ is the set of multiples of 21, this count is $|A \cup B| - |A \cap B|$.

Total numbers $N = 10,000$.
1. Count multiples of 3: $|A| = \lfloor 10000/3 \rfloor = 3333$.
2. Count multiples of 7: $|B| = \lfloor 10000/7 \rfloor = 1428$.
3. Count multiples of 21: $|A \cap B| = \lfloor 10000/21 \rfloor$.
   $10000 = 21 \times 476 + 4$. So, $|A \cap B| = 476$.

The number of integers divisible by 3 or 7 is:
$|A \cup B| = |A| + |B| - |A \cap B| = 3333 + 1428 - 476 = 4761 - 476 = 4285$.

We want the count of those divisible by 3 or 7, excluding those divisible by 21.
Count $= |A \cup B| - |A \cap B| = 4285 - 476 = 3809$.

**Answer 1: 3809**

### 2. Modular Arithmetic
We need to find $7^{2026} \pmod{100}$. We look for the order of 7 modulo 100.
$7^1 \equiv 7 \pmod{100}$
$7^2 = 49 \pmod{100}$
$7^3 = 343 \equiv 43 \pmod{100}$
$7^4 = 7 \times 43 = 301 \equiv 1 \pmod{100}$.
The order of 7 modulo 100 is 4.

We divide the exponent 2026 by 4:
$2026 = 4 \times 506 + 2$.

$$7^{2026} = 7^{4 \times 506 + 2} = (7^4)^{506} \cdot 7^2$$
Since $7^4 \equiv 1 \pmod{100}$:
$$7^{2026} \equiv (1)^{506} \cdot 49 \equiv 49 \pmod{100}$$

**Answer 2: 49**

### 3. Tiling Problem
Let $a_n$ be the number of ways to tile a $2 \times n$ board using $1 \times 2$ dominoes and $2 \times 2$ squares. We seek $a_{12}$.

We establish a recurrence relation by considering how the rightmost column(s) are covered:
1. A vertical $1 \times 2$ domino covers the last column ($n$). Remaining board: $2 \times (n-1)$. Contribution: $a_{n-1}$.
2. Two horizontal $1 \times 2$ dominoes cover the last two columns ($n, n-1$). Remaining board: $2 \times (n-2)$. Contribution: $a_{n-2}$.
3. A $2 \times 2$ square covers the last two columns ($n, n-1$). Remaining board: $2 \times (n-2)$. Contribution: $a_{n-2}$.

The recurrence is $a_n = a_{n-1} + 2a_{n-2}$.

Base cases:
$a_0 = 1$ (empty board, one way to tile).
$a_1 = 1$ (must use a vertical domino).

Calculation:
$a_2 = a_1 + 2a_0 = 1 + 2(1) = 3$.
$a_3 = a_2 + 2a_1 = 3 + 2(1) = 5$.
$a_4 = a_3 + 2a_2 = 5 + 2(3) = 11$.
$a_5 = a_4 + 2a_3 = 11 + 2(5) = 21$.
$a_6 = a_5 + 2a_4 = 21 + 2(11) = 43$.
$a_7 = a_6 + 2a_5 = 43 + 2(21) = 85$.
$a_8 = a_7 + 2a_6 = 85 + 2(43) = 171$.
$a_9 = a_8 + 2a_7 = 171 + 2(85) = 341$.
$a_{10} = a_9 + 2a_8 = 341 + 2(171) = 683$.
$a_{11} = a_{10} + 2a_9 = 683 + 2(341) = 1365$.
$a_{12} = a_{11} + 2a_{10} = 1365 + 2(683) = 1365 + 1366 = 2731$.

**Answer 3: 2731**

### 4. Probability (Dice Roll)
Three fair six-sided dice are rolled. Total outcomes $= 6^3 = 216$.
We want the probability that the largest number shown is exactly 4. This means:
1. All rolls must be $\le 4$. (Values $\{1, 2, 3, 4\}$).
2. At least one roll must be exactly 4.

Let $A$ be the event that all rolls are $\le 4$. $|A| = 4^3 = 64$.
Let $B$ be the event that all rolls are $\le 3$. $|B| = 3^3 = 27$.

The number of outcomes where the maximum is exactly 4 is $|A| - |B| = 64 - 27 = 37$.

The probability is $\frac{37}{216}$. Since 37 is prime and $216 = 2^3 \cdot 3^3$, the fraction is in lowest terms.

**Answer 4: 37/216**

### 5. Conditional Probability
Let $C_1$ and $C_2$ be the two children. Let $B_i$ be the event child $i$ is a boy, and $T_i$ be the event child $i$ was born on Tuesday.
Let $E$ be the conditioning event: "At least one child is a boy born on Tuesday."
We seek $P(\text{Both Boys} | E)$.

Let's use the restricted sample space approach. The total number of possible outcomes for each child is $2 \text{ (gender)} \times 7 \text{ (day)} = 14$. Total sample space size $= 14^2 = 196$.

**Step 1: Calculate the size of event E.**
$E = (\text{C1 is BT}) \cup (\text{C2 is BT})$.
$P(\text{C1 is BT}) = 1/14$. $P(\text{C2 is BT}) = 1/14$.
$P(E) = P(\text{C1 is BT}) + P(\text{C2 is BT}) - P(\text{Both are BT})$
$P(E) = 1/14 + 1/14 - (1/14)^2 = 2/14 - 1/196 = 1/7 - 1/196$
$P(E) = (28 - 1)/196 = 27/196$.

**Step 2: Calculate the probability of (Both Boys AND E).**
Let $X$ be the event that both are boys. $P(X) = (1/2)(1/2) = 1/4$.
If both are boys, the probability that $E$ occurs is the probability that at least one of them was born on Tuesday.
Given both are boys, there are $7 \times 7 = 49$ equally likely day combinations.
The number of ways neither is Tuesday is $6 \times 6 = 36$.
The number of ways at least one is Tuesday is $49 - 36 = 13$.
$P(E | X) = 13/49$.

$P(\text{Both Boys AND E}) = P(E | X) \cdot P(X) = (13/49) \cdot (1/4) = 13/196$.

**Step 3: Apply conditional probability.**
$$P(\text{Both Boys} | E) = \frac{P(\text{Both Boys AND E})}{P(E)} = \frac{13/196}{27/196} = \frac{13}{27}$$

**Answer 5: 13/27**
