## Behaviour notes

- Rendering modes are preserved: `/`, `/about`, `/search`, `/genres/*` are prerendered; `/books/[slug]` is rendered on every request (the view counter still climbs); `/api/books` is dynamic.
- Unknown URLs and unknown genres serve the full custom 404 inside the layout (404 status). For an unknown **book slug**, the status is still 404 and no book/permalink is served, but the initial server HTML is Next's `notFound()` error shell and the 404 UI hydrates on the client — a Next.js App Router characteristic of `notFound()` in a dynamic route.
- On `/genres/poetry` the 404 page is a dynamic-segment render, so the raw HTML marks "Books" as the current nav link (the old Pages 404 page had no current link); normal pages mark the nav exactly as before.
