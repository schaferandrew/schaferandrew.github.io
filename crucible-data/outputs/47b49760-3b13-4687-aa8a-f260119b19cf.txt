To solve these problems, we proceed as follows:

**1. Integers from 1 to 10,000 divisible by 3 or 7, but not 21.**
Let $A$ be the set of integers divisible by 3, and $B$ be the set of integers divisible by 7.
The number of elements in $A$ is $\lfloor 10000/3 \rfloor = 3333$.
The number of elements in $B$ is $\lfloor 10000/7 \rfloor = 1428$.
The number of elements in $A \cap B$ (divisible by 21) is $\lfloor 10000/21 \rfloor = 476$.
The question asks for elements in $(A \cup B) \setminus (A \cap B)$.
This is $|A| + |B| - 2|A \cap B| = 3333 + 1428 - 2(476) = 4761 - 952 = 3809$.

**2. Remainder when $7^{2026}$ is divided by 100.**
We need to find $7^{2026} \pmod{100}$. First, note that $\phi(100) = 100(1 - 1/2)(1 - 1/5) = 40$.
By Euler's Totient Theorem, $7^{40} \equiv 1 \pmod{100}$.
$2026 = 40 \times 50 + 26$. So $7^{2026} \equiv 7^{26} \pmod{100}$.
$7^2 = 49$.
$7^4 = (50-1)^2 = 2500 - 100 + 1 \equiv 01 \pmod{100}$ is incorrect. Let's re-calculate:
$7^2 = 49$.
$7^4 = 49^2 = 2401 \equiv 01 \pmod{100}$.
Since $7^4 \equiv 1 \pmod{100}$, we divide the exponent by 4:
$2026 = 4 \times 506 + 2$.
Thus, $7^{2026} \equiv (7^4)^{506} \cdot 7^2 \equiv 1^{506} \cdot 49 \equiv 49 \pmod{100}$.

**3. Tiling a $2 \times 12$ board with $1 \times 2$ dominoes and $2 \times 2$ squares.**
Let $a_n$ be the number of ways to tile a $2 \times n$ board.
To cover the end of the board:
- A vertical $1 \times 2$ domino: leaves a $2 \times (n-1)$ board ($a_{n-1}$ ways).
- Two horizontal $1 \times 2$ dominoes: leaves a $2 \times (n-2)$ board ($a_{n-2}$ ways).
- One $2 \times 2$ square: leaves a $2 \times (n-2)$ board ($a_{n-2}$ ways).
The recurrence is $a_n = a_{n-1} + 2a_{n-2}$.
Base cases: $a_0 = 1$, $a_1 = 1$ (one vertical domino).
$a_2 = a_1 + 2a_0 = 1 + 2(1) = 3$.
$a_3 = 3 + 2(1) = 5$.
$a_4 = 5 + 2(3) = 11$.
$a_5 = 11 + 2(5) = 21$.
$a_6 = 21 + 2(11) = 43$.
$a_7 = 43 + 2(21) = 85$.
$a_8 = 85 + 2(43) = 171$.
$a_9 = 171 + 2(85) = 341$.
$a_{10} = 341 + 2(171) = 683$.
$a_{11} = 683 + 2(341) = 1365$.
$a_{12} = 1365 + 2(683) = 2731$.

**4. Probability that the largest number on three dice is exactly 4.**
Let $X$ be the maximum of three dice. We want $P(X=4)$.
$P(X \le 4) = (4/6)^3 = 64/216$.
$P(X \le 3) = (3/6)^3 = 27/216$.
$P(X=4) = P(X \le 4) - P(X \le 3) = (64-27)/216 = 37/216$.

**5. Probability both children are boys given at least one is a Tuesday boy.**
Let $B$ be Boy, $G$ be Girl, and $d \in \{1, \dots, 7\}$ be the day of the week.
The total sample space for two children is $(2 \times 7)^2 = 14^2 = 196$ equally likely outcomes.
Let $E$ be the event "at least one child is a boy born on Tuesday".
The complement $E^c$ is "no child is a boy born on Tuesday".
For each child, there are 14 possibilities. Only one is "Boy born on Tuesday".
So for each child, there are 13 possibilities that are NOT "Boy born on Tuesday".
$|E^c| = 13 \times 13 = 169$.
$|E| = 196 - 169 = 27$.
Now we find the number of outcomes in $E$ where both are boys.
Let child 1 be $(B, d_1)$ and child 2 be $(B, d_2)$.
The condition "at least one is a Tuesday boy" means $d_1=T$ or $d_2=T$.
Total pairs of $(d_1, d_2)$ where at least one is $T$ is $7 + 7 - 1 = 13$.
Since we are restricted to both being boys, the outcomes are $(B, T, B, d_2)$ or $(B, d_1, B, T)$.
There are 7 such pairs for $d_2$ and 7 for $d_1$, but $(B, T, B, T)$ is counted twice.
So there are $7 + 7 - 1 = 13$ outcomes where both are boys and at least one is a Tuesday boy.
The probability is $13/27$.
