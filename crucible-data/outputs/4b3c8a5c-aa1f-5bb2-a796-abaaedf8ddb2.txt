Done! I've created a complete CLI interest calculator with:

**Project Structure:**
- `interest.py` - Main CLI tool (7 commands)
- `test_interest.py` - 34 tests, 99% coverage
- `README.md` - Comprehensive documentation with examples
- `requirements.txt` - Dependencies (click, pytest)

**Commands:**
| Command | Purpose |
|---------|---------|
| `compound` | Compound interest & total amount |
| `simple` | Simple interest |
| `loan` | Loan/mortgage payments (amortization) |
| `savings` | Regular deposits to reach savings goal |
| `apy` | Convert nominal rate to APY |
| `double` | Time to double investment |
| `growth` | Investment growth with contributions |

**Example Usage:**
```bash
python3 interest.py compound 10000 0.05 10 --compounds 12
python3 interest.py loan 200000 0.065 30
python3 interest.py savings 50000 0.04 10 --initial 5000
python3 interest.py growth 10000 0.07 20 --contribution 500
```

**Tests:** All 34 tests pass with 99% coverage.
