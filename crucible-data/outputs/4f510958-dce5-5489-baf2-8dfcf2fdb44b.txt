**Root cause** (reproduced in Chrome via Playwright — dashboard rendered blank user/message even on fresh login):
1. `server.js:31` read `req.cookies.sessionId`, but the session cookie is set with `{ signed: true }`. cookie-parser **deletes signed cookies from `req.cookies`** and puts them in `req.signedCookies` (`node_modules/cookie-parser/index.js:177`), so the lookup always missed → every request hit the error path.
2. `/api/dashboard` returned **200 with `{user:null, dashboardMessage:''}`** instead of a 401 on that error path.
3. `dashboard.html` never checked the response status, so the 200-null body rendered as a blank state.

**Fixes:**
- `server.js` — read `req.signedCookies.sessionId` in `getDashboardData` and `/api/logout`; `/api/dashboard` now returns `401 {error: 'no_session'|'stale_session'|'expired_session'}`; server only listens when run directly (testability).
- `public/dashboard.html` — redirects to `/login.html` on non-OK or missing user (expired sessions now force re-login; auth flow unchanged).

**Browser verification** (real Chrome): fresh login shows `testuser` + welcome message; expired session → `/api/dashboard` 401 → auto-redirect to login, no blank state; stale/missing cookie → 401; zero JS console errors.

**Regression tests** — `test.js` rewritten on `node:test` + native fetch (old file used jest/supertest, which aren't installed, so `npm test` couldn't run): 9 tests pass, including 4 C5 regressions (valid session returns data; expired/stale/missing sessions return 401; logout invalidates).
