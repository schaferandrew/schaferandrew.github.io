**Lesson 1 – Setting up a Next.js Project (React + TypeScript)**  
*Goal:* Get you comfortable with the basic file structure, development server, and pages in a brand‑new Next.js app.

## 🚀 Step‑by‑step

### 1️⃣ Create the project

```bash
# In your terminal, run:
npx create-next-app@latest nextjs-practice --typescript
cd nextjs-practice
```

> **Tip:** `create-next-app` scaffolds a minimal but production‑ready starter.  
> The `--typescript` flag sets up TypeScript right away.

### 2️⃣ Explore the folder tree

```bash
tree -L 2 .
```

You should see something like:

```
.
├── node_modules/
├── public/          # Static files (images, favicon, etc.)
├── src/
│   ├── pages/       # React components that become routes
│   │   └── index.tsx  # Home page
│   ├── styles/
│   │   └── globals.css
│   └── app.tsx
├── .gitignore
├── next.config.js
└── package.json
```

- **`pages/`** – Each file maps to a URL.  
- **`public/`** – Served as static assets; reference them with `/asset.png`.  
- **`src/styles/globals.css`** – Imported in `app.tsx`; applied globally.

### 3️⃣ Run the dev server

```bash
npm run dev
```

Open <http://localhost:3000> in your browser. You should see a default Next.js welcome page that updates live as you edit files.

> **Hot‑reload**: Save any change → browser refresh automatically.  
> This is what we’ll use for all exercises.

### 4️⃣ Add an “About” page

Create `src/pages/about.tsx` with:

```tsx
// src/pages/about.tsx
import type { NextPage } from 'next';

const About: NextPage = () => {
  return (
    <div style={{ padding: '2rem' }}>
      <h1>About This Project</h1>
      <p>This is a simple Next.js + TypeScript starter.</p>
    </div>
  );
};

export default About;
```

Open <http://localhost:3000/about>. You should see the new page.
