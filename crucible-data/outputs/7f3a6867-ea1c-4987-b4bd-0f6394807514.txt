**Key design decisions:**
- Iterates over months (or days for daily compounding) so contributions at any frequency align correctly with compounding periods
- All monetary math uses `Decimal` with `ROUND_HALF_UP` for proper cent rounding
- Errors print to stderr with a short message and exit code 1 — no tracebacks
