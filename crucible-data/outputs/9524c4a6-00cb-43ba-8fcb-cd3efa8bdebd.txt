### Problem 1: Nim-like Game with Memory
**Rules Analysis:**
- Tokens: $n$.
- Allowed moves: $\{2, 3, 5, 7\}$.
- Constraint: Cannot repeat the opponent's previous move.
- Loss condition: Cannot make a legal move (pile empty or no valid move size).
- Goal: Find $n \in [1, 100]$ where the **Second Player (P2)** has a winning strategy.

**Strategy Derivation:**
Let $W$ denote a winning position for the current player to move, and $L$ denote a losing position.
Let $S = \{2, 3, 5, 7\}$.
State is defined by $(n, m)$, where $n$ is current tokens and $m$ is the move just made by the opponent.
- If $n=0$, current player loses ($L$).
- If $n \in S$ and $n \neq m$, current player can take all tokens and win ($W$).
- If $n \in S$ and $n = m$, current player cannot take $n$. They must check other moves $k \in S \setminus \{m\}$. If any $k \le n$, they can move to $(n-k, k)$. If all resulting states are $W$ for the next player, then current is $L$.

Let's compute the status for small $n$.
Let $Win(n, m)$ be true if the current player can force a win given $n$ tokens and previous move $m$.
$Win(n, m) = \exists k \in S, k \neq m, k \le n \text{ such that } Win(n-k, k) \text{ is False}$.
If no such $k$ exists, $Win(n, m) = \text{False}$.
