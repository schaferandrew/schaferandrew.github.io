**1.**  
The formula for compound interest is \(A = P(1 + \frac{r}{n})^{nt}\).  
- Principal \(P = \$5000\)  
- Annual rate \(r = 4\% = 0.04\)  
- Compounded monthly, so \(n = 12\)  
- Time \(t = 3\) years  

\[
A = 5000\left(1 + \frac{0.04}{12}\right)^{12 \times 3}
= 5000\left(1 + 0.003333\ldots\right)^{36}
\]

Compute the factor:  

\[
1.003333^{36} = e^{36\ln(1.003333)}
\approx e^{36 \times 0.003327895}
= e^{0.1198042}
\approx 1.1273
\]

Thus  

\[
A = 5000 \times 1.1273 = 5636.50\ (\text{rounded to the cent})
\]

**2.**  
Area to cover: \(1850\) sq ft.  
Extra for waste: \(10\%\) → multiply by \(1.10\).  

\[
\text{Total area needed} = 1850 \times 1.10 = 2035\ \text{sq ft}
\]

Each box provides \(23.5\) sq ft, so number of boxes required is  

\[
\frac{2035}{23.5} = 86.5957\ldots
\]

Since you cannot buy a fraction of a box, round up to the next whole box: **87 boxes**.

**3.**  
- Distance: \(412\) mi  
- Fuel efficiency: \(34\) mi/gal → gallons used = \(\frac{412}{34}\)  

\[
\frac{412}{34} = 12.117647\ldots \text{ gal}
\]

- Gas price: \$3.89 per gallon  

Cost = \(12.117647 \times 3.89\)  

\[
= 47.057647\ldots
\]

Rounded to the cent: **\$47.06**.

**4.**  
- Pre‑tax amount: \$172.00  
- Tip (18% of pre‑tax): \(0.18 \times 172 = 30.96\)  

Total bill = pre‑tax + tip = \(172.00 + 30.96 = 202.96\)

Split four ways:  

\[
\frac{202.96}{4} = 50.74
\]

Each person pays **\$50.74**.
