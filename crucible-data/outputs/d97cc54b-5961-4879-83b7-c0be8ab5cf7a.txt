## Features Implemented

- **Required flags**: `--principal`, `--rate`, `--compound`, and either `--years` or `--months`
- **Optional contributions**: `--contribution AMOUNT` + `--contribution-frequency {monthly,annually}`
- **JSON output mode** with `--json` flag
- **Proper error handling**: Exits with non-zero status and stderr messages for invalid input (no tracebacks)

## Calculation Logic

- Interest credited at end of each compounding period
- Contributions added after interest (at same moment if applicable)
- Uses Python's `Decimal` for precise financial calculations
- Rounds to cents using standard rounding

## Test Coverage

All 27 tests pass, covering:
- Basic compound interest calculations (annual, quarterly, monthly, daily)
- Zero/negative edge cases
- Monthly and annual contributions
- CLI argument validation and error handling

Run with: `python3 -m interest --principal 1000 --rate 5 --years 1 --compound annually`
