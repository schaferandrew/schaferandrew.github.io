1. First, count numbers divisible by 3 or 7:  
   - Multiples of 3: ⌊10,000/3⌋ = 3,333  
   - Multiples of 7: ⌊10,000/7⌋ = 1,428  
   - Multiples of 21 (both 3 and 7): ⌊10,000/21⌋ = 476  
   By inclusion–exclusion: 3,333 + 1,428 − 476 = 4,285.  
   Subtract those divisible by 21 (already excluded in both counts): 4,285.  
   But we want those NOT divisible by 21, so the count remains 4,285.  
   However, we must exclude those divisible by 21 from the “or” set, which they already are.  
   Actually, the condition is “divisible by 3 or 7 but not by 21”, so we keep the 4,285 and remove the multiples of 21 that were added twice:  
   Since the intersection (divisible by 21) is already excluded from “exactly one”, we simply have:  
   Total = (div by 3) + (div by 7) − 2·(div by 21) = 3,333 + 1,428 − 2·476 = 3,333 + 1,428 − 952 = 3,809.  
   (Alternatively: numbers divisible by 3 only: 3,333 − 476 = 2,857; by 7 only: 1,428 − 476 = 952; total 2,857 + 952 = 3,809.)  
   So the answer is 3,809.

2. Compute \(7^{2026} \bmod 100\).  
   φ(100) = 40, so by Euler’s theorem \(7^{40} \equiv 1 \pmod{100}\).  
   2026 = 40·50 + 26, so \(7^{2026} \equiv 7^{26} \pmod{100}\).  
   Compute powers of 7 modulo 100:  
   \(7^1=7\), \(7^2=49\), \(7^3=343\equiv43\), \(7^4=301\equiv1\pmod{100}\).  
   So the cycle length is 4. Then \(7^{26} = (7^4)^{6} \cdot 7^2 \equiv 1^6 \cdot 49 = 49 \pmod{100}\).  
   Answer: 49.

3. Let \(a_n\) be the number of tilings of a 2×n board with 1×2 dominoes and 2×2 squares.  
   Base cases: \(a_0=1\) (empty board), \(a_1=1\) (only a vertical domino).  
   Recurrence: To tile a 2×n board, consider the rightmost piece.  
   - If it’s a vertical domino covering columns n and n−1, the rest is a 2×(n−1) board: \(a_{n-1}\).  
   - If it’s two horizontal dominoes covering rows 1–2, columns n and n−1: \(a_{n-2}\).  
   - If it’s a 2×2 square covering columns n and n−1: \(a_{n-2}\).  
   So \(a_n = a_{n-1} + 2a_{n-2}\).  
   Compute up to n=12:  
   \(a_0=1\), \(a_1=1\),  
   \(a_2 = a_1 + 2a_0 = 1+2=3\),  
   \(a_3 = a_2 + 2a_1 = 3+2=5\),  
   \(a_4 = a_3 + 2a_2 = 5+6=11\),  
   \(a_5 = a_4 + 2a_3 = 11+10=21\),  
   \(a_6 = a_5 + 2a_4 = 21+22=43\),  
   \(a_7 = a_6 + 2a_5 = 43+42=85\),  
   \(a_8 = a_7 + 2a_6 = 85+86=171\),  
   \(a_9 = a_8 + 2a_7 = 171+170=341\),  
   \(a_{10} = a_9 + 2a_8 = 341+342=683\),  
   \(a_{11} = a_{10} + 2a_9 = 683+682=1365\),  
   \(a_{12} = a_{11} + 2a_{10} = 1365+1366=2731\).  
   So the answer is 2731.

4. Probability that the largest of three dice is exactly 4.  
   Each die shows 1–6, independent.  
   Largest = 4 if all ≤4 and at least one die =4.  
   Total outcomes: 6³=216.  
   Outcomes where all ≤4: 4³=64.  
   Among these, those with no 4’s: 3³=27.  
   So outcomes with max exactly 4: 64−27=37.  
   Probability = 37/216.  
   (Fraction already in lowest terms.)

5. Family has two children, at least one boy born on Tuesday.  
   Let B be the event that both are boys. We want P(both boys | at least one boy born on Tuesday).  
   Each child is a boy or girl (1/2 each), and birth day uniform over 7 days.  
   Total possible genders/days for two children: (2²·7²)=4·49=196.  
   Events with at least one boy born on Tuesday: count all (gender1,gender2,day1,day2) with (boy,*,Tue) or (*,boy,Tue).  
   Count = P(at least one boy with Tuesday birth) = total − none have such a child.  
   Neither has a boy born on Tue: for each, either girl or boy not Tue.  
   For each child: possibilities = 1 (girl) + 6 (boy, not Tue) = 7.  
   So both not having a boy born on Tue: 7·7=49.  
   So events with at least one boy born on Tue: 196−49=147.  
   Now count those where both are boys **and** at least one born on Tue.  
   Total both boys: 1·1·7·7=49.  
   Both boys but neither born on Tue: each boy not born on Tue: 6 choices per child → 6·6=36.  
   So both boys with no boy born on Tue: 36.  
   Thus those both boys and at least one Tue boy: 49−36=13.  
   So probability = 13/147.  
   (Fraction already in lowest terms.)
