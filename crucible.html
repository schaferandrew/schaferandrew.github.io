Crucible runs the same real-world prompts in two separate sections that are never ranked together. Chat tests (writing, math, geography, history, general knowledge) are a single API call with no tools. Agentic tests (coding, research and everyday tasks) run in an agent harness, opencode or pi, that can edit files, run commands and browse. Each run is scored 0–10 against the test's rubric. Tests come in three tiers: Spark (the basics, pass or fail), Temper (everyday work, the headline score) and Forge (long, multi-step work you'd normally need a frontier model for).     Models

    How scores are made. Writing, math, geography and history tests are scored by programmatic checks: fixed rules applied to the model's answer, the same way every time (listed on the About page). Other tests are scored by an AI judge (Claude) against the test's rubric, with hidden acceptance tests for Forge. Judge scores are a rough signal, not a precise eval, so treat differences of a point or two as noise.
