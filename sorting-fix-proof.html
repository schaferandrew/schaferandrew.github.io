✓ Fix: Sort by Run Date - Oldest First

🐛 The Bug

The original sorting logic in assets/js/crucible-run.js had inverted comparison operators:

// BEFORE (BUGGY)
case 'date-desc':
  return (b.started_at || '') > (a.started_at || '') ? 1 : -1;
case 'date-asc':
  return (a.started_at || '') < (b.started_at || '') ? 1 : -1;

This caused both sorting directions to produce incorrect results.

✅ The Fix

Changed to use localeCompare() for reliable string comparison:

// AFTER (FIXED)
case 'date-desc':
  return (b.started_at || '').localeCompare(a.started_at || '');
case 'date-asc':
  return (a.started_at || '').localeCompare(b.started_at || '');
