✅ Local Proof: Date Sorting Fix

Test with Realistic Data (including runs without dates)

This simulates the actual Crucible runs dashboard behavior.

Expected Behavior

  • Newest first: Runs with dates sorted descending (newest to oldest), runs without dates at the END
  • Oldest first: Runs with dates sorted ascending (oldest to newest), runs without dates at the END

The Fix (in assets/js/crucible-run.js)

// BEFORE (BUGGY) - null dates sorted to front case 'date-desc': return (b.started_at || '') > (a.started_at || '') ? 1 : -1; case 'date-asc': return (a.started_at || '') < (b.started_at || '') ? 1 : -1; // AFTER (FIXED) - null dates always at end case 'date-desc': if (!a.started_at && !b.started_at) return 0; if (!a.started_at) return 1; if (!b.started_at) return -1; return b.started_at.localeCompare(a.started_at); case 'date-asc': if (!a.started_at && !b.started_at) return 0; if (!a.started_at) return 1; if (!b.started_at) return -1; return a.started_at.localeCompare(b.started_at);
